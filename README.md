# TheSecondToLastCaretaker

An experimental "see each other" multiplayer mod for **The Last Caretaker**.
Each player plays their own game; the mod shows your friend's character moving around in your
world. Nothing else is shared. Built on [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS).

Status: early development — see `docs/03-roadmap.md`.

Not affiliated with Channel 37. Early Access game: expect every patch to break something.
